# Sobat RentCar Semarang

Website Sobat RentCar Semarang dibangun dengan TanStack Start, React, Vite, dan Tailwind CSS.

## Development

Persyaratan: Bun dan Node.js versi 22.12 atau lebih baru.

```powershell
bun install
bun run dev
```

## Validasi

```powershell
bun run lint
bun run test
bun run build
```
